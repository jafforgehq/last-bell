## What the owner decided (and what this round does with it)

- Only the player goes beyond the walls, leads, recruits, fights with real aim, drives. Colonists stay in unless asked along (round 17) or **sent on an errand** (this round).
- An errand without the player works but does **worse**: loot x0.6, no rare finds, no rescue, no vehicle recovered, a worse clearing chance, wounds x1.5, losses far likelier (numbers in S2.1).
- **Requests, not commands.** A refusal has a visible reason, shown where it was asked (table at the end); trust sets the tone and the delay of an answer; nothing is random. A *roster* change (job, post) is a plan, not a movement: it is accepted or refused at once with the person's line, and the person then walks to the seat at their own pace; the speed of trust shows in the delay of the verbs and of errands, which start after the radio's `delay_s`.
- Box select is gone (round 17). The Town Board becomes the **Map page**, the Duty roster the **Jobs page**, the Build screen the **Build page**, the News log the **News page**, all in one **non-modal radio panel**: the game does not pause, WASD still walks, the avatar stays in view.

### S2.1 ERRANDS (`scavenge.gd`, `radio.gd`, `jobs.gd`)

```
# scavenge.gd: a delegated errand is a dice trip in avatar mode (the player's own trips are `begin_played`, never dice).
const ERRAND_LOOT := 0.6               # the trip's loot scale is multiplied by this (after the raid, lone and leader factors)
const ERRAND_WOUND := 1.5              # each member's wound chance x1.5
const ERRAND_LOSS_PER_DANGER := 0.03   # each member's chance of not coming back is at least 0.03 x difficulty mult x (danger + nest), from danger 1 up
const ERRAND_CLEAR := -0.2             # added to the chance of clearing a place (the 0.1 to 0.95 limits stay)
func is_errand(party) -> bool          # String(sim.player_id) != "" and not bool(party.get("played", false))
func errand_terms() -> Dictionary      # {"loot": 0.6, "wound": 1.5, "loss_per_danger": 0.03, "clear": -0.2, "extras": false, "rescue": false, "vehicle": false}
func clear_chance(people, place_id, errand := false) -> float   # the existing function, with `errand` the ERRAND_CLEAR applies
```
Applied in `_decide_town` and `_decide` (the dice stay in step: every die is still thrown, only what is done with it changes): `scale *= ERRAND_LOOT`; the `extra` finds are rolled but not added; `loss` uses `maxf(LOSS_BASE * mult * (effective / 2.0), ERRAND_LOSS_PER_DANGER * mult * effective)` when `effective >= 1` (was `>= LOSS_MIN_DANGER`); `wound_p *= ERRAND_WOUND` (before the clear-failure x2.5); the clear roll uses `clear_chance(.., true)`; `rescue = false`; the town place's vehicle is never got running (`result.vehicle` not set); beats and scout reveals are unchanged. `party.result.errand = true` (kept by `_copy_result`). `_tell` adds "Without you along they found less." when loot came home from an errand, and (avatar mode, dice trips only) `radio.log_news("errand", ...)` on departure ("Dez and Ana set off for the pharmacy. They will find less without you.") and on return/loss (the same text as the banner). Players' trips and the old game are untouched.
