## The contract between tasks

`stations.json` gets a `work` word per station (task WORKLIFE adds it): bench "bench", builders "hammer" (a site) / "mend" (a wall to repair) / "haul" (nothing to do: sorting materials), garden "garden", infirmary "nurse", radio "radio", watch "watch", salvage "sort". `Person.work` (a String, "" when not working) is set by the rules each step: it is the goal's `work` word while the person stands within 0.6 tile of the goal's spot and is not walking, else "". `Person.work_t` counts the seconds the work has gone on (resets when `work` changes). Also `"rest"` for a person at ease at the rest spot. Task ANIMS draws from `p.work`/`p.work_t` only; it never changes rules.
